# طريقة تشغيل المشروع

## 1. تحميل المشروع

قم بتحميل المشروع ثم افتحه باستخدام **Visual Studio Code** أو محرر الأكواد الذي تفضله.

## 2. تثبيت المشروع

افتح **Terminal** أو **Command Prompt** داخل مجلد المشروع، ثم نفّذ الأمر التالي:

```bash
pip install -e .
```

هذا الأمر يقوم بتثبيت المشروع في وضع **Editable**، بحيث يمكنك تعديل الكود مباشرة أثناء تطوير المشروع دون الحاجة إلى إعادة تثبيته بعد كل تعديل.

## 3. تشغيل الأداة

من نفس مجلد المشروع، استخدم الأمر:

```bash
ftool
```

ثم أضف الأمر والخيارات التي تريد تنفيذها.

### مثال: حذف ملف

لحذف ملف باسم `f.txt`:

```bash
ftool del f.txt
```

بشكل افتراضي، يقوم الأمر `del` بنقل الملف إلى **سلة المحذوفات الخاصة بالأداة** بدلًا من حذفه نهائيًا.

### مثال آخر

لحذف مجلد بشكل recursive:

```bash
ftool del -r my_folder
```


### استرجاع ملف من سلة المحذوفات

بعد حذف ملف أو مجلد بالأمر `del` (بدون `--final`) يمكنك استرجاعه إلى مكانه الأصلي:

```bash
ftool restore f.txt
```

إذا حُذف العنصر أكثر من مرة، يُسترجع آخر إصدار محذوف.

عرض محتويات سلة المحذوفات (الأحدث أولًا):

```bash
ftool restore --list
```

معاينة الاسترجاع دون تنفيذه:

```bash
ftool restore --dry-run f.txt
```

#### خيارات الأمر

| الخيار | الوصف |
|---|---|
| `-l`, `--list` | عرض محتويات سلة المحذوفات |
| `--dry-run` | محاكاة الاسترجاع دون تنفيذه |
| `-q`, `--quiet` | عدم طباعة رسالة النجاح (تبقى رسائل الخطأ ظاهرة) |

> **ملاحظات:**
> - إذا كان المسار الأصلي موجودًا حاليًا فلن يُستبدل، وسيظهر خطأ؛ انقل الملف الموجود أو غيّر اسمه ثم أعد المحاولة.
> - الحذف النهائي (`--final`) لا يمكن التراجع عنه ولا يظهر في السلة.
> - تُحفظ السلة في المسار `~/.local/share/ftool/trash`.

> **ملاحظة:** يجب تنفيذ أوامر `ftool` من Terminal بعد تثبيت المشروع باستخدام `pip install -e .`.
